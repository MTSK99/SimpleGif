# SimpleGif

下载推特 GIF 用于微信。

## 网络要求

App 需要访问 X 才能解析和下载，手机必须能打开 X 本身。开着代理（VPN 模式）时会自动接管，不需要单独设置。

## 下载

安装包在 [Releases](https://github.com/MTSK99/SimpleGif/releases)。

## 注意事项

- 只支持 **Android 10 及以上**、**arm64** 架构。2020 年之后的手机基本都是，老旧的 32 位设备装不上
- 首次安装需要在系统里允许「安装未知来源应用」
- 只处理公开内容：删除的推文、仅粉丝可见的、纯图片的页面都转不了
- B 站的番剧、付费课程这类需要登录的内容同样不支持
- 超过 20 秒的视频**只取前 8 秒**。GIF 体积随时长膨胀，整段转会糊到没法看
- 微信表情库对单个动图有约 **5MB** 上限，超出只能当普通图片发，加不进表情
- 转码时别切到后台，可能被系统回收，白等一场
- 站外链接只支持 B 站，其他站点请先用别的工具下载再转换
